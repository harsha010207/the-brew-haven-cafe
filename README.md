# ☕ The Brew Haven – Café Website

A modern and responsive café website created using **HTML, CSS, and JavaScript**. The website provides information about the café, its menu, gallery, and contact details.

## 🌐 Live Website

After enabling GitHub Pages, add your live website link here.

## 📌 About the Project

**The Brew Haven** is a café website designed to provide visitors with an attractive and easy-to-use online experience.

The website includes multiple pages for exploring the café, viewing its menu and gallery, and getting in touch through the contact page.

## ✨ Features

* 🏠 Home page with café introduction
* 📖 About Us page
* ☕ Café menu
* 🖼️ Image gallery
* 📩 Contact page
* 📱 Responsive design for mobile and desktop
* 🎨 Modern and clean user interface
* ✨ Smooth animations

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Website functionality
* **AOS (Animate On Scroll)** – Scroll animations
* **Unsplash** – Images used in the website

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.

No additional software or installation is required.
